
# SmartHealthcare 🏥

## Big Data Analytics and Patient Similarity-Based Recommendation System

SmartHealthcare is a healthcare analytics project built using Python and Streamlit. It provides an interactive dashboard to analyze patient data and generate recommendations based on similarities between patient records.

## Features
- Interactive healthcare dashboard with a dark theme
- Patient details input
- Patient similarity-based recommendations
- Healthcare data analysis and visualization
- Statistical summaries and graphical insights

## Technologies Used
- Python
- Streamlit
- Pandas and NumPy
- Scikit-learn
- Plotly

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
streamlit run app.py
```
